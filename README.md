Formula 1 ERS Monza Simulator

This project investigates how Energy Recovery System (ERS) deployment strategies and regenerative braking efficiency affect simulated Formula 1 lap performance at the Monza Circuit.

Software

MATLAB

How to Run

Download F1_Monza_Performance_Optimizer.m.

Open the file in MATLAB.

Click Run.

Adjust the simulation parameters using the application interface.

Compare lap times, energy recovery, and battery energy across different ERS strategies.

Investigations

Deployment strategies: Conservative, Balanced, Aggressive, and Low-Speed Priority.

Recovery efficiency: 50%, 70%, and 90%.

Note

This simulator uses simplified vehicle-dynamics and thermodynamic assumptions for educational purposes. Its results are not intended to predict actual Formula 1 lap times.
